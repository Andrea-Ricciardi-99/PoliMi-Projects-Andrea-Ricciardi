# Time Series Forecasting – Code Modules

This folder contains the core components for our time series forecasting project.  
It is divided into three main sections, each with a specific role in the workflow.

---

## 📂 generated-samples-processing

**Purpose:**  
Preprocess the synthetic time series generated by **TimeGAN** before they are added to the training dataset.  

**Key steps include:**
- Cleaning and shaping the generated data to match the format of real samples.
- Applying noise filtering (e.g., Gaussian smoothing) to reduce artifacts.
- Adjusting sequences to align with real-world category characteristics.

---

## 📂 model-ts-aug

**Purpose:**  
Build and train the **time series forecasting model** with both real and augmented data.  

**Main features:**
- Auto-regressive forecasting architecture with a ResNet-inspired CNN backbone.
- Multihead attention mechanism for improved temporal pattern recognition.
- Integration of category encoding alongside time series inputs.
- Flexible input length for iterative forecasting (e.g., 6-step increments to reach the target horizon).

---

## 📂 timegan_X

**Purpose:**  
Generate additional training data using **TimeGAN** to address class imbalance and improve model generalization.  

**Details:**
- Trains a GAN to produce realistic sequences for underrepresented categories.
- Generator: Conv1D-based network for local temporal feature synthesis.
- Discriminator: LSTM-based network to capture temporal correlations.
- Trained with a higher update frequency for the generator to ensure loss convergence.
- Outputs fixed-length padded sequences for downstream preprocessing.

---

### 🛠 Workflow Overview

1. **Data Generation** (`timegan_X`)  
   Train TimeGAN and produce synthetic time series samples for target categories.

2. **Sample Processing** (`generated-samples-processing`)  
   Clean, filter, and format generated sequences for compatibility with the real dataset.

3. **Model Training** (`model-ts-aug`)  
   Train the forecasting model using a mix of real and synthetic data, leveraging the augmented dataset for improved accuracy and robustness.
